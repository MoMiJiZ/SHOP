# คู่มือแก้ไขเว็บร้านค้า

เว็บนี้เป็นไฟล์ HTML/CSS/JavaScript ล้วน ไม่ต้องติดตั้งโปรแกรมเพิ่ม
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome, Edge, Safari) ก็ดูหน้าเว็บได้ทันที
โปรแกรมที่ใช้แก้ไฟล์ แนะนำ Visual Studio Code (ฟรี) หรือ Notepad ก็ได้

## ไฟล์ในโฟลเดอร์มีอะไรบ้าง

| ไฟล์ / โฟลเดอร์ | ใช้ทำอะไร | ต้องแก้ไหม |
|---|---|---|
| `js/config.js` | ชื่อร้าน ข้อความ รูปหน้าแรก ช่องทางติดต่อ ค่าส่ง การชำระเงิน | แก้ |
| `js/products.js` | รายการสินค้าทั้งหมด | แก้ |
| `images/` | เก็บรูปทั้งหมดของเว็บ | ใส่รูปจริงแทน |
| `css/style.css` | สีและฟอนต์ (แก้เฉพาะส่วน `:root` บรรทัดบนสุด) | แก้ได้ถ้าอยากเปลี่ยนสี |
| `index.html` | หน้าแรก | ไม่ต้องแก้ |
| `product.html` | หน้ารายละเอียดสินค้า | ไม่ต้องแก้ |
| `cart.html` | หน้าตะกร้า | ไม่ต้องแก้ |
| `checkout.html` | หน้ากรอกที่อยู่และสรุปคำสั่งซื้อ | ไม่ต้องแก้ |
| `js/app.js` | ระบบตะกร้าและการสั่งซื้อ | ไม่ต้องแก้ |

## หน้าแรกเรียงจากบนลงล่าง

1. แถบข้อความดำบนสุด → `announcement` ใน config.js
2. เมนูและชื่อร้าน → `name`, `logo`
3. ภาพหลักใหญ่เต็มจอ → `hero`
4. แถวสินค้าแนะนำเลื่อนซ้ายขวา → `featuredIds` (ใส่ id สินค้าที่อยากโชว์)
5. บล็อกภาพคู่ข้อความ → `stories` (เพิ่มลบได้ ภาพสลับซ้ายขวาเอง)
6. แคตตาล็อกสินค้าทั้งหมด มีแท็บหมวด ช่องค้นหา และภาพใหญ่แทรกกลาง → `CATEGORIES`, `catalogFeatureImage`
7. ภาพปะติดสามใบ → `community`
8. ท้ายเว็บ → `about`, ช่องทางติดต่อ

ส่วนไหนไม่อยากใช้ ให้เว้นค่าว่าง เช่น `announcement: ""` หรือ `stories: []` ส่วนนั้นจะหายไปเอง

## วิธีเปลี่ยนรูป

1. เอารูปจริงไปวางในโฟลเดอร์ `images`
2. ตั้งชื่อไฟล์เป็นภาษาอังกฤษ ไม่มีเว้นวรรค เช่น `lip-01.jpg`
3. แก้ชื่อไฟล์ใน config.js หรือ products.js ให้ตรง เช่น `images: ["images/lip-01.jpg"]`

ตัวพิมพ์เล็กพิมพ์ใหญ่ต้องตรงกันทุกตัว (`Lip.JPG` กับ `lip.jpg` ถือเป็นคนละไฟล์เมื่อขึ้นเว็บจริง)

ขนาดรูปที่แนะนำ

| รูป | ขนาด |
|---|---|
| รูปสินค้า | 1000 × 1000 px (จัตุรัส) |
| ภาพหลักหน้าแรก | 1600 × 900 px |
| ภาพบล็อกคู่ข้อความ | 1200 × 900 px |
| ภาพใหญ่ในแคตตาล็อก | 1200 × 1200 px |
| ภาพปะติด | 800 × 800 px |

รูปแต่ละไฟล์ควรไม่เกินประมาณ 300 KB เว็บจะโหลดเร็ว ย่อรูปได้ฟรีที่ squoosh.app หรือ tinypng.com

รูปตัวอย่างที่ให้มาเป็นไฟล์ `.svg` (ภาพเปล่าที่มีตัวหนังสือบอกขนาด) เปลี่ยนเป็นรูปจริงแล้วลบทิ้งได้ ยกเว้น `no-image.svg` ที่ใช้แสดงแทนเวลาหารูปไม่เจอ

## วิธีเพิ่มสินค้า

ใน `js/products.js` ให้คัดลอกก้อนสินค้า 1 ก้อน ตั้งแต่ `{` ถึง `},` แล้ววางต่อท้าย จากนั้นแก้ข้อมูล

```js
  {
    id: "p009",
    name: "ลิปทินต์ สีชมพูนม",
    short: "เนื้อบางเบา ติดทน",
    price: 350,
    category: "ลิป",
    images: ["images/tint-pink.jpg"],
    description: "ขนาด 4 กรัม\nทาได้ทั้งปากและแก้ม",
    options: ["Pink Milk", "Rose"]
  },
```

ข้อควรระวัง
- `id` ห้ามซ้ำกับสินค้าอื่น
- ราคาใส่เป็นตัวเลขล้วน ไม่ใส่ `฿` หรือ `,`
- ข้อความต้องอยู่ในเครื่องหมาย `"..."` และท้ายบรรทัดต้องมี `,`
- `category` ต้องสะกดตรงกับรายการ `CATEGORIES` ใน config.js
- สินค้าไม่มีตัวเลือก ให้ลบบรรทัด `options` ทิ้งทั้งบรรทัด การ์ดจะมีปุ่ม "ใส่ตะกร้า" ให้กดได้ทันที

ถ้าแก้แล้วหน้าเว็บขาวหรือสินค้าหายหมด มักเกิดจากลืมเครื่องหมาย `,` `"` หรือ `}` ให้ย้อนดูบรรทัดที่เพิ่งแก้

## วิธีเปลี่ยนสีทั้งเว็บ

เปิด `css/style.css` แก้รหัสสีในส่วน `:root` บรรทัดบนสุด เช่น

```css
--accent: #d9708f;   /* สีชมพู เปลี่ยนเป็นสีประจำร้านได้ */
--ink: #111111;      /* สีตัวหนังสือและปุ่ม */
```

ถ้าอยากให้การ์ดและปุ่มมีมุมมน แก้ `--radius: 0px;` เป็น `--radius: 16px;`

## การสั่งซื้อทำงานอย่างไร

เว็บนี้ไม่มีระบบหลังบ้านและไม่มีระบบตัดเงินอัตโนมัติ ลำดับการสั่งซื้อคือ

1. ลูกค้าเลือกสินค้าใส่ตะกร้า (ตะกร้าเก็บไว้ในเบราว์เซอร์ของลูกค้าเอง)
2. กรอกชื่อ เบอร์โทร ที่อยู่ เลือกวิธีชำระเงิน
3. เว็บสร้างสรุปรายการสั่งซื้อพร้อมเลขที่คำสั่งซื้อ
4. ลูกค้ากดปุ่ม "ส่งรายการทาง LINE" หรือ "คัดลอกรายการ" ไปส่งให้ร้าน
5. ร้านตรวจสลิปและยืนยันออเดอร์ในแชทเอง

ให้ปุ่ม LINE เปิดแชทกับร้านโดยตรง ต้องใส่ LINE ID ของ LINE Official Account ใน `lineOA` เช่น `"@myshop"`
ถ้าเว้นว่างไว้ ปุ่มจะเปิดหน้าให้ลูกค้าเลือกเองว่าจะส่งข้อความไปแชทไหน

## วิธีเอาเว็บขึ้นออนไลน์ (ฟรี)

ทางที่ 1 GitHub Pages
1. สมัคร github.com แล้วสร้าง repository ใหม่ แบบ Public
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (ให้ `index.html` อยู่ชั้นนอกสุด)
3. ไปที่ Settings → Pages เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/ชื่อrepository/`

ทางที่ 2 Netlify
1. สมัคร netlify.com
2. ใช้ Netlify Drop ลากโฟลเดอร์ทั้งโฟลเดอร์ไปวาง ได้ลิงก์เว็บทันที

ทั้งสองทางเป็นโฮสต์สำหรับเว็บแบบไฟล์นิ่ง ข้อมูลทุกอย่างในโฟลเดอร์จะเปิดดูได้สาธารณะ จึงไม่ควรใส่รหัสผ่านหรือข้อมูลลับไว้ในไฟล์ใดๆ
